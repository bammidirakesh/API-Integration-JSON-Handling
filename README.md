# API Integration & JSON Handling

## Project Description

This project is a Python-based API integration application that demonstrates how to communicate with an external REST API and handle JSON data.

The application uses the JSONPlaceholder Users API to fetch user information and provides options to display, search, filter, refresh, and exit.

## Features

- Fetch user data from an external API
- Parse JSON responses
- Display all users
- Search users by name
- Filter users by city
- Refresh API data
- Handle API connection and HTTP errors
- Menu-driven interface

## Technologies Used

- Python 3
- Requests Library
- JSON
- REST API
- Visual Studio Code

## API Used

JSONPlaceholder Users API:

https://jsonplaceholder.typicode.com/users
